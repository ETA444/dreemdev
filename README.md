# dreemdev
Archiving useful scripts, configs, templates and projects.

- `dotfiles/.zshrc`: main zsh config (oh-my-zsh, theme, plugins, aliases).
- `tools/`: scripts and configs I reuse across machines and projects.
- `projects/`: small apps, experiments, and learning projects (by language).

## Repository structure

```text
dreemdev/
├─ README.md          # This file
├─ dotfiles/          # Versioned configs (e.g. .zshrc)
├─ tools/             # Scripts, configs, templates
│  ├─ configs/        # App / service configs (filters, settings, etc.)
│  └─ scripts/        # Utility scripts (setup, automation, helpers)
└─ projects/          # Code projects and playgrounds
   ├─ python/         # Python DS/ML playgrounds and projects
   └─ r/              # R playgrounds and projects
```
